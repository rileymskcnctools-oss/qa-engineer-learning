## 学习路线建议

```
L1 Ch00 价值与体系（先搞清为什么写用例）
   ↓
L1 Ch01-Ch04 四种黑盒设计方法（选数据的功夫）
   ↓
L1 Ch05 基础概念 → Ch06 设计与评审 → Ch07 面试（8 要素是地基）
   ↓
L2 Ch02 因果图 / Ch04 正交法 / Ch08 模型驱动 / Ch09 白盒（补逻辑与组合）
   ↓
L3 Ch10-Ch13 文档流    需求分析 → 计划 → 方案 → 报告
L3 Ch14-Ch16 用例产出  思维导图 → 用例表 → 测试数据
   ↓                    ↑ 人调 AI 干活
L3 Ch17-Ch18 自动化    工作流 → 智能体
   ↓                    ↑ AI 自己编排干活
L3 Ch19 手工用例（回到 AI 覆盖不到的部分 ← 资深测试的核心价值）
```

> **如果时间紧，优先学这 4 篇**（面试高频 + 性价比最高）：
> Ch05 基础概念（8 要素是地基）· Ch07 面试用例设计 · Ch15 AI 编写用例 · Ch18 智能体生成用例
