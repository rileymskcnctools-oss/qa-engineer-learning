## 一、什么是弱网测试

### 知识点 1：弱网测试的概念与价值

【课程原话/定义】
移动互联网时代网络形态多变（2G/3G/4G/5G、不同制式速率），移动产品使用场景多变（地铁、公交、电梯、山区）。一般应用**低于 3G 的可以划分为弱网**，弱信号的 Wifi 也可纳入弱网场景。弱网测试是**健壮性测试**的重要部分，对移动端测试必不可少。弱网测试主要进行特殊网络状态下的功能测试，同时关注用户体验。

【为什么？】
为什么要专门做弱网测试？因为用户不是在"满格 Wifi"下用 App——地铁里信号断断续续、电梯里网络掉线、山区只有 2G。这些场景下 App 表现如何（卡顿、白屏、崩溃、重复提交、数据丢失）直接决定用户体验和口碑。弱网测试就是提前模拟这些"恶劣网络"，验证 App 的健壮性：断网能不能优雅提示、弱网下能不能降级、网络恢复能不能自动重连。

【必须掌握】
- 弱网：低于 3G 或弱信号 Wifi 的网络
- 弱网测试 = 健壮性测试的一部分，移动端必不可少
- 测的是"特殊网络状态下的功能 + 用户体验"
- 典型关注点：卡顿、白屏、崩溃、重复提交、断网提示、自动重连

【企业场景】
你在公司测一个 App，除了常规功能，还会专门做一轮弱网测试：用 Charles 限速模拟 2G/3G，观察 App 在弱网下是否卡死、请求超时是否有友好提示、弱网下重复点击是否造成重复下单（这又和 Ch08 的幂等关联）、网络恢复后是否自动重连。这是移动端测试的必测项，面试也常被问到。

【面试考察】
面试官："什么是弱网测试？为什么要做？怎么测？"

参考回答框架：
1. 弱网 = 低于 3G 或弱 Wifi，弱网测试是健壮性测试的一部分
2. 价值：模拟地铁/电梯/山区等真实弱网场景，验证 App 的健壮性和用户体验
3. 手段：用 Charles/Fiddler 限速模拟 2G/3G，观察功能 + 体验
4. 关注：卡顿、超时提示、重复提交、断网重连

【易错点】

| 常见错误 | 正确理解 |
|----------|----------|
| 弱网测试 = 断网测试 | 弱网是"慢/不稳定"，断网是"完全没网"，两者都要测但不完全一样 |
| 只测 App 不关注用户体验 | 弱网测试既要测功能正确，也要关注卡顿/等待体验 |
| 弱网测试和性能测试混淆 | 性能测试测"高负载下快不快"，弱网测试测"恶劣网络下能不能用" |

## 二、使用 Charles 完成弱网测试

### 知识点 2：Charles Throttle 弱网模拟

【课程原话/定义】
使用 Charles 完成弱网测试：`Proxy → Throttle Settings`，勾选 `Enable Throttling`。可对指定域名配置（`Only for selected hosts`），不设置则对所有域名生效。

弱网参数：
- **Throttle Preset**：选择网络类型（如 56 kbps modem）
- **Bandwidth**：带宽
- **Utilisation**：利用百分比
- **Round-trip latency**：往返延迟(Ms)
- **MTU**：最大传输单位(字节)
- **Reliability**：可靠性(%)
- **Stability**：稳定性(%)

基础模拟：点击小乌龟 → 刷新页面 → 打开 Charles 的 overview 查看响应时间。

【为什么？】
为什么弱网模拟的本质是"控制这几个参数"？因为真实弱网的表现就由这几个量决定：带宽（每秒传多少）、延迟（往返多久）、丢包（可靠性）、抖动（稳定性）。Charles 的 Throttle 就是让你手动调这几个参数，逼真模拟 2G/3G/弱 Wifi。理解参数含义，才能"定向"模拟——比如想测"高延迟"就调 Round-trip，想测"丢包"就调 Reliability。

【必须掌握】
- 入口：Proxy → Throttle Settings → 勾选 Enable Throttling
- 预设：Throttle Preset 直接选网络类型（56 kbps modem 等）
- 核心参数：Bandwidth(带宽)、Round-trip(往返延迟)、Reliability(可靠性/丢包)、Stability(稳定性/抖动)
- 可指定域名（Only for selected hosts），不指定则全局生效
- 小乌龟图标 = 快速开关弱网

【企业场景】
你在公司测 App 弱网：Charles 里勾 Enable Throttling，选 56 kbps modem 模拟 2G，然后操作 App，看请求是不是超时、页面是不是卡顿、有没有友好提示。想模拟"丢包严重"就把 Reliability 调低（如 50%），模拟"延迟高"就把 Round-trip 调大。这就是用 Charles 做弱网测试的标准操作。

【面试考察】
面试官："Charles 怎么做弱网测试？主要调哪些参数？"

参考回答框架：
1. Proxy → Throttle Settings → Enable Throttling
2. Throttle Preset 选预设网络（如 56kbps modem）
3. 自定义参数：Bandwidth(带宽)、Round-trip(延迟)、Reliability(丢包)、Stability(抖动)
4. 可指定域名或全局生效，观察 App 在弱网下的表现

【易错点】

| 常见错误 | 正确理解 |
|----------|----------|
| 忘了勾 Enable Throttling | 弱网设置不生效 |
| 只想测某域名却全局限速 | 应勾 Only for selected hosts 并指定 hosts |
| Bandwidth 和 Round-trip 混淆 | Bandwidth 是带宽（速率），Round-trip 是往返延迟 |
