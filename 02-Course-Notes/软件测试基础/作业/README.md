# 软件测试基础 — 作业

## 作业：测试方案设计实战

对应课程：[[Ch17-测试方案设计实战（五位一体）]]

任务：为你熟悉的一款产品（或核心功能）设计一份完整的测试方案。

### 文件说明

| 文件 | 用途 |
|------|------|
| [[测试方案-空壳框架]] | 你的作业模板，按章节填空即可 |
| [[朋友圈发布图片功能测试方案-示例]] | 老师给的完整范例，参考结构和写法 |

### 作业要求（摘自 Ch17 Part 9）

- **产品选择**：公司内部产品，或知名公共产品（微信小程序、支付宝模块、抖音功能、淘宝流程等）
- **必含 6 章节**：项目概述、诊断与分析、测试策略、测试计划、团队与能力、风险评估
- **输出格式**：PPT 15-20 页 或 Word 10-15 页，图文并茂
- **评分标准**：设计完整性 40% · 专业深度 30% · 创新价值 20%（含 AI 测试加分项）· 表达呈现 10%
