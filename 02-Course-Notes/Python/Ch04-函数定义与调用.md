# Ch04 - 函数定义与调用

## 1. 知识点理解

> 一句话解释：函数是把一段会重复使用的代码打包成"工具"，给它起个名字，需要时就喊它干活。

| 维度          | 说明                                                        |
| ----------- | --------------------------------------------------------- |
| **一句话解释**   | 封装一段逻辑 → 起名 → 需要时调用，写完一次到处用                               |
| **为什么需要**   | 同样逻辑写三遍 = 改四遍（改了三处还漏一处）。函数让你只写一次、改一次、测一次                  |
| **在测试中的作用** | 测试脚本的核心就是函数——每个测试用例是一个函数，公共操作（登录、造数据、清数据）封装成函数，用例里只调用不重复写 |

## 2. Python 语法

### 2.1 函数的四个组成部分

```python
#  函数名   参数（可选）       返回值（可选）
#   ↓        ↓                  ↓
def add(a, b):                   # ① 函数名 + ② 参数
    """返回两个数的和"""          # 文档注释
    result = a + b               # ③ 函数体
    return result                # ④ 返回值
```

| 部分  | 说明                      | 必须？                       |
| --- | ----------------------- | ------------------------- |
| 函数名 | 调用时用的名字，命名规则同变量（小写+下划线） | ✅                         |
| 参数  | 函数运行时需要的外部数据            | ❌ 可以没有                    |
| 函数体 | 实际执行的代码                 | ✅                         |
| 返回值 | 函数执行完交出去的结果             | ❌ 没写 `return` 默认返回 `None` |

---

### 2.2 函数定义

#### 语法格式

```python
def function_name([parameter_list]):
    """注释信息"""
    function_body
    return [result]
```

#### 示例代码

```python
# 最简单的函数：无参数，无返回值
def show():
    """输出 Hogwarts"""
    print("Hogwarts")

# 直接运行什么都不发生——只是定义了函数，没有调用
```

#### 代码解释

| 行                   | 作用                                                |
| ------------------- | ------------------------------------------------- |
| `def show():`       | `def` 关键字声明"我要定义一个函数"，`show` 是函数名，`()` 空括号表示不需要参数 |
| `"""输出 Hogwarts"""` | docstring，文档注释                                    |
| `print("Hogwarts")` | 函数体，调用时才执行                                        |

> **关键理解**：定义函数 ≠ 执行函数。就像菜谱写好了不等于菜做好了——得有人按菜谱做菜（调用）。

---

### 2.3 函数调用

#### 语法格式

```python
function_name([parameters_value])
# 括号不能省！show 是函数对象，show() 才是调用
```

#### 示例代码

```python
def show():
    """输出 Hogwarts"""
    print("Hogwarts")

print("第一次调用")
show()                          # 调用！

print("第二次调用")
show()                          # 再调用！

print("程序执行结束")

# 输出：
# 第一次调用
# Hogwarts
# 第二次调用
# Hogwarts
# 程序执行结束
```

#### 代码解释

| 行           | 作用                                |
| ----------- | --------------------------------- |
| `show()`    | 程序跳到 `def show` 处执行函数体，执行完跳回来继续往下 |
| 两次 `show()` | 同一段代码执行两次——这就是"可重复使用"             |

---

### 2.4 函数返回值

#### 语法格式

```python
def function_name():
    return 值
# 遇到 return 立刻结束函数，返回到调用处
# 没写 return → 默认返回 None
```

#### 示例代码

```python
# 有 return
def get_number():
    num = input("请输入一个数字：")
    num = int(num)
    return num                # 把数字交出去

# 用返回值
result = get_number()         # result 拿到用户输入的数字
print("hello" * result)       # 用这个数字重复字符串

# 无 return → 返回 None
def say_hello():
    print("hello")

x = say_hello()               # 打印 hello，但 x 的值是 None
print(x)                      # None
```

#### 代码解释

| 行 | 作用 |
|----|------|
| `return num` | ① 结束函数 ② 把 `num` 的值交给调用者 |
| `result = get_number()` | 接收返回值，赋给 `result` |
| `x = say_hello()` | 函数没有 `return` → 默认返回 `None` |

### 2.5 函数参数：实参 vs 形参

#### 语法格式

```python
def add(a, b):       # a, b 是形式参数（形参）——占位置的变量
    return a + b

print(add(1, 2))     # 1, 2 是实际参数（实参）——真正参与计算的值
```

#### 示例代码

```python
def add(a, b):
    return a + b

print(add(1, 2))     # 1+2 → 3
print(add(3, 4))     # 3+4 → 7
print(add(10, 20))   # 10+20 → 30
# 同一个函数，不同的实参 → 不同的结果
```

#### 代码解释

| 概念 | 是什么 | 在代码里 |
|------|--------|---------|
| 形参 | 函数定义时写的变量名，占位置的 | `def add(a, b):` 里的 `a`、`b` |
| 实参 | 函数调用时传的实际值 | `add(1, 2)` 里的 `1`、`2` |
| 过程 | 实参的值赋给形参 → 函数里用形参计算 → 返回结果 | `1→a, 2→b, a+b=3` |

#### 测试中的参数模式

```python
# 测试登录：username 和 password 作为参数
def login(username, password):
    """模拟登录，返回结果"""
    if username == "admin" and password == "123456":
        return {"code": 200, "msg": "success"}
    return {"code": 401, "msg": "fail"}

# 同一函数，不同参数 → 测不同场景
print(login("admin", "123456"))   # 正确账号 → 200
print(login("admin", "wrong"))    # 错误密码 → 401
print(login("hacker", "123456"))  # 不存在用户 → 401
```

## 4. 易错点

| 常见错误 | 错误原因 | 解决方法 |
|---------|---------|---------|
| 定义完函数不调用 | 只写了 `def xxx():` 没写 `xxx()` | 定义 ≠ 执行，需要主动调用 |
| 调用时忘写括号 | `show` 只是函数对象，`show()` 才是执行 | 括号不能省 |
| `return` vs `print` 搞混 | `return` 是交出结果给调用者，`print` 是显示到屏幕 | 想要值继续用 → `return`；只想看一眼 → `print` |
| 实参和形参数量不对 | `def f(a, b)` 但你调用 `f(1)` 少了一个 | Python 报 `TypeError: missing 1 required argument` |
| 忘了 `return` 导致返回 `None` | 写了好多逻辑但没 `return`，调用方拿到 `None` | 如果你需要调用方得到结果，必须写 `return` |

## 7. 面试输出

> 30 秒能说完的回答。

**问题：Python 函数中形参和实参有什么区别？return 和 print 有什么区别？**

**回答：** 形参是函数定义时写的占位变量（`def f(a, b)` 里的 a、b），实参是调用时传的具体值（`f(1, 2)` 里的 1、2）。`return` 是把计算结果交给调用者继续用，`print` 只是显示到屏幕。测试里最关键的区别：`return` 的值能用 `assert` 做验证，`print` 的值只能用眼睛看。
