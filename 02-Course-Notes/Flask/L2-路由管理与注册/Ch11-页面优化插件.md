## 一、Flask-Bootstrap 集成

### 知识点 1：用 Bootstrap 快速美化页面

【课程原话/定义】
对前端不熟悉的开发者，原生写 HTML/CSS 成本高。用响应式前端框架 Bootstrap + Flask 的 flask-bootstrap 插件，可以快速搭建精美页面。

使用步骤：
1. 安装：pip install flask-bootstrap
2. templates 下建 base.html，加一行继承：
   ```html
   {% extends "bootstrap/base.html" %}
   ```
3. 启动处传入 app：
   ```python
   from flask_bootstrap import Bootstrap
   app = Flask(__name__)
   Bootstrap(app)
   ```
4. 新建页面 bootstrap_index.html，用 {% include 'base.html' %} 引入，再放 Bootstrap 官方组件

【为什么？】
为什么测试工程师要学 Flask-Bootstrap？因为测试平台通常由测试工程师自研，而测试的前端功底普遍弱于专业前端。Flask-Bootstrap 把 Bootstrap 的样式封装成插件，你只需 extends base.html + 复制官方组件，就能得到漂亮的响应式页面，不用手写 CSS。这大大降低了测试自建平台的门槛——后端逻辑才是重点，前端用现成组件拼装即可。

【必须掌握】
- 安装 flask-bootstrap
- base.html 加 {% extends "bootstrap/base.html" %}
- Bootstrap(app) 初始化
- 页面 {% include 'base.html' %} 引入 + 放 Bootstrap 组件
- Bootstrap 是响应式前端框架，提供按钮/导航/表格等现成组件

【企业场景】
你在公司自建测试平台，需要一个好看的后台页面。用 Flask-Bootstrap 继承 base.html，从 Bootstrap 官方复制一个 Dashboard 导航组件，几分钟就有了带导航栏、侧边栏、表格的响应式页面，不用从零写 CSS。这是测试平台"快速出 UI"的常用手段。

【面试考察】
面试官：「测试平台前端怎么快速做？不会前端怎么办？」

参考回答框架：
1. 用 Flask-Bootstrap 插件集成 Bootstrap 前端框架
2. extends base.html 继承样式
3. 复制 Bootstrap 官方组件拼装页面
4. 降低前端门槛，专注后端逻辑

【易错点】

| 常见错误 | 正确理解 |
|----------|----------|
| 直接手写 CSS 从零开始 | 用 Bootstrap 现成组件，节省时间 |
| 忘 Bootstrap(app) 初始化 | 要传 app 实例，否则插件不生效 |
| extends 和 include 混淆 | base.html 用 extends 继承，页面用 include 引入 |
