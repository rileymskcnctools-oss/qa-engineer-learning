## 一、文件上传接口

### 知识点 1：files 参数上传文件

【课程原话/定义】
自动化测试中会遇到上传图片/文件的接口，其头部 Content-Type 为 `multipart/form-data; boundary=...`。Python 用 requests 的 `files` 参数上传。

files 为字典类型，键是参数名，值是元组 `(文件名, 文件流, content-type)`：
```python
files = {
    "file": ("攀登者.png", open("C:/Users/A/Desktop/攀登者.png", "rb"), "image/png")
}
r = requests.post("https://httpbin.ceshiren.com/post", files=files)
```
除上传的文件外，接口其他参数用 `data` 传递，不能放 files 里。

【为什么？】
为什么文件上传要用 multipart/form-data、用 files 参数？因为文件是二进制数据，不能用普通表单的 key=value 表示。multipart 把"文件内容 + 文件元信息（文件名、类型）"打包成一个多部分的消息体，每个部分用 boundary 分隔。requests 的 files 参数帮你自动完成这个打包（元组三元组 = 文件名 + 内容 + 类型），你只要指定文件路径和参数名即可。

【必须掌握】
- 文件上传：Content-Type 是 multipart/form-data
- files 参数是字典：键=参数名，值=元组(文件名, 文件流, content-type)
- 文件用 "rb"（二进制读）打开
- 其他参数用 data 传，不能混进 files

【企业场景】
你在公司测一个"上传头像"接口，用 `files={"file": ("avatar.png", open(path,"rb"), "image/png")}` 上传图片，其他字段（如用户 id）用 data 传。如果传错（把普通参数塞进 files），服务器会解析失败。files 参数是文件上传接口的标准写法。

【面试考察】
面试官："Requests 怎么上传文件？files 参数的值是什么格式？"

参考回答框架：
1. 用 files 参数，字典格式
2. 键=参数名，值=元组(文件名, 文件流, content-type)
3. 文件以 "rb" 二进制模式打开
4. 对应 Content-Type 是 multipart/form-data

【易错点】

| 常见错误 | 正确理解 |
|----------|----------|
| 文件用 "r" 读 | 二进制文件要用 "rb" 读 |
| 普通参数塞进 files | 文件以外的参数用 data 传 |
| 忘记 content-type | 元组第三个元素是文件类型（如 image/png） |

【我的理解】
> （为什么上传文件的 Content-Type 是 multipart/form-data，而不是 application/json？文件这种"二进制数据"和 JSON 这种"文本数据"在传输上有什么本质区别？）
