## 说明

本目录聚焦 **APP（移动端）自动化测试**，技术主线：

```
Python 进阶回顾（闭包/装饰器、异常处理、sys/os 模块）
          → Appium 环境与元素定位 → Pytest 组织用例
          → Page Object 分层 → Allure 报告 → CI 持续集成
```

前 4 章（Ch01–Ch04）是 **Python 进阶回顾**：闭包与装饰器、异常处理、sys/os 模块。这些是后续 Appium PO 框架的硬前提——装饰器支撑数据驱动与日志/截图装饰，异常处理支撑失败留证，os/sys 支撑日志与截图目录、路径管理。Appium 正式内容随后展开。

学习路线（由浅入深）：

1. Python 进阶回顾（闭包/装饰器、异常、os/sys）— Ch01–Ch04
2. Appium 环境搭建、第一个脚本（跑得起来）— 后续章节
3. 元素定位 + 手势操作 + 等待机制 — 后续章节
4. Pytest + PO 设计模式 + Allure（工程化）— 后续章节
