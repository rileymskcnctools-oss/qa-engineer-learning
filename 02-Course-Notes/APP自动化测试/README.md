## 说明

本目录聚焦 **APP（移动端）自动化测试**，技术主线：

```
Python 进阶回顾（闭包/装饰器、异常处理、sys/os、日志模块）
          → App 自动化价值与体系 → Appium 环境与元素定位 → Pytest 组织用例
          → Page Object 分层 → Allure 报告 → CI 持续集成
```

前 5 章（Ch01–Ch05）是 **Python 进阶回顾**：闭包与装饰器、异常处理、sys/os、日志模块。这些是后续 Appium PO 框架的硬前提——装饰器支撑数据驱动与日志/截图装饰，异常处理支撑失败留证，os/sys 支撑日志与截图目录、路径管理，logging 支撑日志留证（事后排查）。Ch06 起进入 App 自动化正式内容。

学习路线（由浅入深）：

1. Python 进阶回顾（闭包/装饰器、异常、os/sys、日志）— Ch01–Ch05
2. App 自动化价值与体系 — Ch06
3. Appium 入门：基本介绍（Ch07）→ 环境安装（Ch08）→ 原理解析（Ch09）→ 第一个脚本的用例结构（Ch10）
4. 元素定位 + 手势操作 + 等待机制 — 后续章节
5. Pytest + PO 设计模式 + Allure（工程化）— 后续章节
