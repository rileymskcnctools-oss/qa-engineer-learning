## 一、parametrize + mark + xfail/skip 组合实战

### 知识点 1：参数化 + 优先级标记 + 跳过/预期失败

【课程原话/定义】
对加法计算器 add(a, b) 做参数化实战，综合运用 parametrize、mark、xfail、skip：

```python
class TestAdd:
    def setup_method(self):
        print("开始计算")
    def teardown_method(self):
        print("结束计算")
    def teardown_class(self):
        print("结束测试")

    @pytest.mark.P0
    @pytest.mark.parametrize("a, b, expect", [
        [1, 1, 2], [-0.01, 0.02, 0.01], [10, 0.02, 10.02]
    ], ids=["int", "float", "int_float"])
    def test_add_P0(self, a, b, expect):
        result = add(a, b)
        assert result == expect

    @pytest.mark.xfail            # 特殊字符场景预期失败
    @pytest.mark.P1
    @pytest.mark.parametrize("a, b, expect", [
        ["*&", 0.2, "a参数为非数字"], [21.45, "@", "b参数为非数字"]
    ])
    def test_add_special(self, a, b, expect):
        result = add(a, b)
        assert result == expect

    @pytest.mark.skip            # 空输入场景跳过
    @pytest.mark.P2
    @pytest.mark.parametrize("a, b, expect", [
        [None, 20.93, "a参数为非数字"], [" ", 3.14, "a参数为非数字"]
    ])
    def test_add_None(self, a, b, expect):
        result = add(a, b)
        assert result == expect
```

【为什么？】
为什么这个实战重要？因为它把 L2 学到的多个知识点"串"起来了：parametrize（数据驱动）、mark（优先级标签 P0/P1/P2）、xfail（预期失败）、skip（跳过）。真实项目里，一个测试类往往同时用这些技术——正向用例标 P0、边界标 P1、特殊字符标 xfail、空输入标 skip。这个实战演示了"多技术组合"的完整场景，是 L2 的综合验收。理解它，就知道"参数化 + 标记 + 跳过/预期失败"怎么在真实用例里配合。

【必须掌握】
- parametrize 传多组数据 + ids 重命名
- mark P0/P1/P2 分优先级
- xfail 标预期失败、skip 标跳过
- 多个装饰器叠加（parametrize + mark + xfail/skip）
- 测试装置（setup_method/teardown）配合参数化

【企业场景】
你在公司写接口测试，同一个接口用 parametrize 传多组数据（正常/边界/异常），正向标 P0、边界标 P1、已知 bug 标 xfail、暂不支持的标 skip。一份代码覆盖多场景，用 mark 管理优先级，用 xfail/skip 管理已知问题。

【面试考察】
面试官：「怎么用 parametrize + mark + xfail/skip 组织完整测试？」

参考回答框架：
1. parametrize 传多组数据（正常/边界/异常）
2. mark 分优先级 P0/P1/P2
3. xfail 标预期失败、skip 标跳过
4. 多装饰器叠加组合使用

【易错点】

| 常见错误 | 正确理解 |
|----------|----------|
| 装饰器顺序搞错 | parametrize 要在最外层（靠测试函数最近） |
| xfail 用例意外通过 | 显示 XPASS，要关注是否需要去掉 xfail |
| mark 自定义标签未注册 | 自定义 mark 要在 pytest.ini 注册避免 warning |
