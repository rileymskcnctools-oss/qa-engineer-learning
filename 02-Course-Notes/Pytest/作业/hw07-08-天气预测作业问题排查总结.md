# hw07 / hw08 天气预测作业问题排查总结

> 核心问题：hw07/hw08（天气预测 + Allure）跑不起来，PyCharm 识别不到用例。根因 = 3 个环境问题 + 1 个配置问题 + 1 个 fixture 缺失 + 1 个被测代码的"时间炸弹"。

---

## 一、uv 环境问题（已解决）

### 1. 缺依赖

`test_weather.py` 里 `import yaml`，hw08 用 `@allure.feature/story/title` 装饰器，但 `pyproject.toml` 只声明了 pytest + pytest-order，导致导入失败、用例收集不到。

| 缺失依赖 | 用到的地方 | 补充声明 |
|---------|-----------|---------|
| pyyaml | hw07 `import yaml` | `pyyaml>=6.0` |
| allure-pytest | hw08 `@allure.*` 装饰器 | `allure-pytest>=2.13` |
| pytest-xdist | hw07 需求"并行执行" | `pytest-xdist>=3.5` |

### 2. Python 版本 3.13 而非 3.12

venv 是 3.13.13，约定是 3.12.13。根因：`pyproject.toml` 只有 `requires-python = ">=3.12"`，没有 `.python-version` 锁版本，`uv sync` 抓了最新版。

**教训**：uv 项目必须放 `.python-version`（内容 `3.12`）锁版本，否则 `uv sync` 会自动升级到最新 Python。

修复：新增 `.python-version`=`3.12` → `rm -rf .venv && uv sync` 重建为 3.12.13。

## 二、pytest.ini 配置问题（已解决）

原配置：

```ini
addopts = --maxfail=5 --disable-warnings  # 设置最多失败5次，禁用警告
```

INI 文件**不支持行内注释**，`#` 及后面文字被当成 addopts 值，pytest 报 `ERROR: file or directory not found: #`，导致收集不到用例。

修法：注释单独成行、`#` 顶格：

```ini
addopts = --maxfail=5 --disable-warnings
# 设置最多失败5次，禁用警告
```

## 三、fixture 缺失（已解决）

4 个用例用 `weather_predictor`，但全仓库没定义（只有 `weather_predictor_empty`）。pytest 报 `fixture 'weather_predictor' not found`，4 个用例 ERROR、只剩 `test_get_current_weather_empty` 通过。

修法：照 `weather_predictor_empty` 的样子补一个 `weather_predictor` fixture。

## 四、被测代码的"时间炸弹"（待解决 · 思考题）

`weather.py` 的 `get_current_weather`：

```python
return self.weather_data[city][str(datetime.date.today())]
```

`weather_data` 里只有固定历史日期 `2023-10-01`、`2025-02-10`，但 `date.today()` 是"今天"，不在数据里 → `KeyError`。

**症状**：`test_get_current_weather_valid` 断言 temp=-7（对应 2025-02-10 那条数据），实际抛 KeyError。

> 思考题：测试期望"当前天气"返回 2025-02-10 的数据，但代码查的是"今天"。要让测试和代码对齐，应该改哪里？（提示：对比 `get_historical_weather` 的用法——它是怎么处理"指定日期"的？）

## 五、PyCharm 解释器（附注）

重建 venv 后，PyCharm 项目解释器名字带 `(2)`（如 `Python 3.12 (作业) (2)`），且 PyCharm 注册表里残留 2 个 Python 3.13 旧条目。

确认方法：**Settings → Project → Python Interpreter**，核对①路径指向 `...\Pytest\作业\.venv\Scripts\python.exe`、②版本 3.12.13、③能看到 pytest/allure-pytest/pyyaml。不对就 Add Interpreter → Existing 重选。
