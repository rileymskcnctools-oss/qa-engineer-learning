# 性能测试

> 复习优先级：⭐⭐⭐ 投简历必掌握 · ⭐⭐ 重要加分 · ⭐ 了解即可

性能测试能力是测开工程师的**精华加分项**——它回答的不是"功能对不对"，而是"多少人来、来多久，系统还对不对"。本课程从"什么是性能测试"入手，核心地基是**性能压力曲线模型**（三条曲线 / 三个区域 / 两个拐点），它是压测场景设计、容量评估、瓶颈定位的共同语言。

> 课程站点：`performance.tutorial.hogwarts.ceshiren.com` → `performance/性能测试体系/L1/...`（分 L1~L5 五级；本模块为 **L1 性能测试体系**）

## 能力四级阶梯（自评用）

| 级别 | 能力 | 可检验的标志 |
|------|------|--------------|
| L0 会用工具 | 会用 JMeter / LoadRunner 跑脚本 | 能按模板录制并跑出报告 |
| L1 会设计场景 | 从业务量推导并发模型，设计基准 / 负载 / 压力 / 稳定性场景 | 能独立写压测方案并定 SLA |
| L2 会定位瓶颈 | 结合监控（CPU / 内存 / IO / JVM / DB）定位到具体层 | 能指着数据说"瓶颈在这个接口的这条 SQL" |
| L3 会调优 | 改配置 / 改代码 / 改架构并量化收益 | 优化前后有对比数据，能算省了多少钱 |

> 课程原话：能做调优的测试，基本都是资深专家以上的级别——所以调优不必急于吹会，先把 L1（场景设计）和 L2（瓶颈定位）打通。
