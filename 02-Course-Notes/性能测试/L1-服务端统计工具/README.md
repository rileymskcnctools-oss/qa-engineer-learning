## 本模块必须能"背下来"的三件事

1. **排查方向链**：`uptime`/`vmstat` 定性（CPU？内存？IO？）→ `mpstat`/`iostat`/`free`/`ss` 定量到具体资源 → `top`/`ps` 落到进程与线程。
2. **三个最容易被误读的信号**：`wa` 高＝在等 IO（不是 CPU 瓶颈）；`available` 小 + `si/so` 非 0＝内存不足（会伪装成磁盘问题）；`load` 高但 CPU 不高＝一堆进程卡在 `D` 状态（等 IO）。
3. **top 与 ps 的分工**：top＝录像（现场交互排查），ps＝照片（脚本/留证据/前后对比）。
