## 本模块必须能"背下来"的三件事

1. **变量 vs 属性**：变量**线程私有**（每个线程一份，UDV 也只是"复制给每个线程的初始集"）；属性**全 JVM 共享**，用 `${__setProperty(名,值)}` 写、`${__P(名,默认值)}` 读。课程原文"变量可以跨线程传参"是错的。
2. **求值时机决定用途**：UDV 测试开始一次（不能放 `${__Random}`、不能引用运行期变量）→ CSV 每迭代一行 → 函数/元件每次调用 → 提取器每次响应后。选型口诀："值变不变、什么时候变"。
3. **引用失败是静默的**：`${未定义变量}` 不报错、原样输出。验证必须两步走——Debug Sampler 看值、View Results Tree 看请求里是否真替换，正式压测前删掉这两个调试元件。
