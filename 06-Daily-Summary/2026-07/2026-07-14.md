## 企业真实场景

> 今天三章是 Python 基础的核心底盘。类型转换（Ch06）解决"数据格式不对"——从 Excel/JSON/CSV 读出的永远是字符串；运算符（Ch07）解决"数据怎么算"——分页、比较、条件组合；字符串（Ch08）解决"文本怎么处理"——这是覆盖面最广的一章，30+ 个方法但核心只有 10 个：len/find/split/join/replace/strip/切片/f-string/startswith/isdigit。三章学完，Python 基础的数据操作闭环成型：变量存（Ch05）→ 类型转换清洗（Ch06）→ 运算符加工（Ch07）→ 字符串处理（Ch08）。

## 收获

1. 类型转换是"数据清洗层"——`input()` 和文件读取后必须做，自动化测试每天写
2. `int("3.14")` 报错因为 int() 不支持浮点字符串，正确姿势：`int(float("3.14"))`
3. `bool("False")` → `True`，因为非空字符串都是真——这是面试最高频陷阱
4. 短路机制让 `False and 1/0` 不会报错，测试中用于 `if response and response.get("key")`
5. `n *= 3 + 4` 展开是 `n = n * (3 + 4)`，不是 `n = n * 3 + 4`——复合赋值不简单展开
6. find 返回 -1 vs index 抛异常——测试中根据"不确定有"vs"必须有"选择
7. 切片 `[::-1]` 逆序是最简洁写法；`split`+`join` 是数据处理最基本组合拳
8. f-string 优于 format()——可读性、性能、支持表达式；测试代码里无脑用
9. Python 数据操作闭环成型：Ch05(变量) + Ch06(转换) + Ch07(运算符) + Ch08(字符串)
