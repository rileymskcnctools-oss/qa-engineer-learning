## 企业真实场景

> 今天 Ch06 CSS 补上了前端三件套的最后一块。至此：HTML（结构）+ CSS（样式）+ JS（行为）全部覆盖。CSS 对测试的核心价值有三：① 选择器是自动化定位的最强武器；② 盒子模型是你解释"为什么按钮比设计稿宽"的根因分析工具；③ 定位（position）是 90% 布局 Bug 的源头。一个看不懂盒子模型的测试，面对"元素重叠"Bug 只能说"不知道"，而懂的人会打开 Computed 面板逐层排查。

## 收获

1. CSS 选择器是 querySelector 的核心，比 getElementsByClassName 强大灵活得多
2. `[data-testid]` 属性选择器是自动化测试最佳实践
3. CSS 三种引入方式优先级：内联 > 内部 > 外部
4. 5 种定位：static(默认) / relative(相对自身) / absolute(相对父元素) / fixed(相对窗口) / sticky(粘性)
5. 盒子模型四层：content → padding → border → margin
6. `box-sizing: border-box` 解决"宽度总比预期大"的经典问题
7. 前端三件套全闭环：HTML+CSS+JS
