# 换机迁移指南

> 从零到完全恢复工作环境，按顺序操作。

---

## 第一步：安装基础工具

### 1.1 Python
- 下载 Python 3.11+（当前用 3.11.14）
- 安装时勾选 "Add Python to PATH"

### 1.2 Git
- 下载 Git for Windows
- 安装后用终端验证：`git --version`

### 1.3 PyCharm
- 下载 PyCharm Community（免费版够用）
- 或用 Professional 版（学校邮箱可免费申请）

### 1.4 Obsidian
- 下载 Obsidian（知识库就是 Obsidian vault）
- 安装后先不打开

---

## 第二步：克隆知识库

```bash
cd ~/Desktop/code
git clone https://github.com/rileymskcnctools-oss/qa-engineer-learning.git
```

克隆后目录结构：
```
C:\Users\<你的用户名>\Desktop\code\qa-engineer-learning\
```

> 根目录下的 `AGENTS.md` 是 Hermes 学习教练规则，不用动。

---

## 第三步：PyCharm 配置（3 处关键设置）

### 3.1 打开项目
PyCharm → Open → 选择 `qa-engineer-learning` 文件夹

### 3.2 切换默认测试执行器 ⭐ 最重要
```
File → Settings → Tools → Python Integrated Tools
→ Default test runner: 选 pytest
→ OK
```

> 不切的话：绿色三角不出现、fixture 不生效、参数化报错。

### 3.3 确认 Python 解释器
PyCharm 右下角 → 检查解释器指向你安装的 Python 3.11+
如果不是：点击 → Add Interpreter → 选你的 Python

### 3.4 验证配置
在 PyCharm 中打开任意 `test_*.py` 文件，测试函数左侧应有绿色三角。

---

## 第四步：安装 Python 依赖

在项目目录下终端执行：
```bash
pip install pytest pyyaml
```

当前版本参考：
- pytest 9.0.2
- PyYAML（最新即可）

后续按课程进度安装：
```bash
pip install pytest-order        # 执行顺序控制
pip install pytest-xdist         # 并行/分布式
pip install pytest-html          # HTML 报告
pip install allure-pytest        # 企业级报告（推荐）
pip install pytest-timeout       # 超时控制（推荐）
```

验证安装：
```bash
pytest --version
```

---

## 第五步：Obsidian 打开知识库

1. 打开 Obsidian
2. "Open folder as vault" → 选择 `qa-engineer-learning` 文件夹
3. 知识库自动识别所有 `[[]]` 双向链接

知识库结构：
```
qa-engineer-learning/  (= Obsidian vault)
├── 00-首页（Dashboard）/    ← 学习总览
├── 01-学习路线/              ← 6个月规划
├── 02-课程笔记/              ← 核心笔记（13门课）
├── 03-项目/
├── 04-面试/
├── 05-Bug记录/
├── 06-英语/
├── 07-每日总结/
├── 08-资源/
└── AGENTS.md                ← Hermes 自动加载
```

---

## 第六步：Hermes Agent

### 6.1 确保 Hermes 正在运行
在新电脑上启动 Hermes Agent，进入 `qa-engineer-learning` 目录后，Hermes 自动读取 `AGENTS.md` 加载所有学习教练规则。

### 6.2 验证
在 Hermes 终端中发送"今天学了什么"，应能正确读取知识库并回复。

> AGENTS.md = 唯一依赖。不需要额外配置，git clone 后 Hermes 自动识别。

## 跨设备工作流

```
┌──────────────────────────────────────────┐
│  电脑 A（当前）                            │
│  写完笔记 → git push                      │
└──────────────────────────────────────────┘
                    ↓
┌──────────────────────────────────────────┐
│  电脑 B（新）                              │
│  开始前：git pull                         │
│  学习 → 写笔记 → git push                 │
└──────────────────────────────────────────┘
```

**每次换电脑的固定操作：**

拉开工前：
```bash
cd ~/Desktop/code/qa-engineer-learning
git pull origin main
```

收工后：
```bash
git add -A
git commit -m "日常更新"
git push origin main
```

## 常见问题

### Q: 绿色三角不出现？
A: Settings → Tools → Python Integrated Tools → Default test runner 没切到 pytest。

### Q: `pytest` 命令找不到？
A: Python 没加到 PATH，或者没 `pip install pytest`。

### Q: 导入报错 `ModuleNotFoundError`？
A: PyCharm 右下角解释器选错了，切到正确的 Python。

### Q: Obsidian 链接点不开？
A: vault 根目录选错了，应该是 `qa-engineer-learning` 而不是其父目录。

### Q: Hermes 不认识我？
A: 确认当前目录是 `qa-engineer-learning/`，AGENTS.md 在根目录。Hermes 进这个目录自动加载。
