## 二、项目背景

**企业微信部门管理接口自动化测试**

企业微信是腾讯微信团队打造的企业通讯与办公工具，提供丰富的 API 接口。本项目围绕企业微信通讯录管理接口，从零搭建一个完整的接口自动化测试框架。

**环境准备**：
- 企业微信注册：https://work.weixin.qq.com/
- 白名单配置：https://ceshiren.com/t/topic/22768
- 获取 corpid：管理后台 → 【我的企业】→【企业信息】→【企业ID】
- 获取 corpsecret：管理工具 → 通讯录同步 → 通讯录管理 secret

## 三、接口鉴权机制

企业微信接口鉴权分两步：

```
1. 调用认证接口 → 获取 access_token
2. 业务接口调用 → 带上 access_token 参数
```

**认证接口**：
```
GET https://qyapi.weixin.qq.com/cgi-bin/gettoken?corpid=ID&corpsecret=SECRET
```

**响应格式**：
```json
{
  "errcode": 0,
  "errmsg": "ok",
  "access_token": "4APkdftnYvupILvFp3A8W...",
  "expires_in": 7200
}
```

**关键点**：
- token 有效期 7200 秒（2小时）
- 每天获取次数有限制
- 必须缓存，不能每个用例都重新获取

### 6.1 BaseApi — requests 统一封装

**文件**：`frame/base/base_api.py`

```python
import requests
from interface_auto.frame.utils.log_util import logger

class BaseApi:
    def send_api(self, req: dict):
        '''
        对 requests 进行二次封装
        req 格式：
        {
            "method": "post",
            "url": "https://...",
            "params": {},
            "json": {}
        }
        '''
        logger.info(f"请求数据为：{req}")
        r = requests.request(**req)  # ** 解包字典
        logger.info(f"响应数据为 {r.text}")
        return r
```

**设计意图**：
- 统一日志记录（请求/响应）
- 统一异常处理入口
- 方便后续扩展（重试、超时、断言）

### 6.2 Wework — Token 获取与缓存（核心）

**文件**：`frame/apis/wework.py`

```python
import time
from interface_auto.frame.base.base_api import BaseApi
from interface_auto.frame.utils.file_util import get_path, get_yaml_data, write_yaml_data

class Wework(BaseApi):
    REFRESH_BEFORE_EXPIRE = 600  # 提前 600 秒刷新
    CORPSECRET = None
    CONFIG_PATH = get_path("config")
    CONFIG_FILE = CONFIG_PATH / "test_env.yaml"
    CACHE_FILE = CONFIG_PATH / "token_cache.yaml"

    def __init__(self):
        self.config_data = get_yaml_data(self.CONFIG_FILE)
        self.get_config()
        self.token = self.get_access_token()

    def get_access_token(self):
        # 1. 用 corpid_corpsecret 作为缓存 key
        app_key = f"{self.corpid}_{self.corpsecret}"
        cache_data = self._load_cache() or {}
        cached = cache_data.get(app_key)

        # 2. 检查缓存是否有效（提前 600 秒刷新）
        if cached and self._is_token_valid(cached):
            return cached["token"]

        # 3. 缓存失效，重新获取
        token_info = self._fetch_token_from_api()
        cache_data[app_key] = token_info
        self._save_cache(cache_data)
        return token_info["token"]

    def _is_token_valid(self, token_info):
        expires_at = token_info.get("expires_at", 0)
        return time.time() < expires_at - self.REFRESH_BEFORE_EXPIRE

    def _fetch_token_from_api(self):
        url = f"{self.base_url}/cgi-bin/gettoken"
        params = {"corpid": self.corpid, "corpsecret": self.corpsecret}
        req = {"method": "GET", "url": url, "params": params}
        r = self.send_api(req)
        response_data = r.json()

        token = response_data.get("access_token")
        expires_in = response_data.get("expires_in", 7200)
        obtained_at = time.time()

        return {
            "token": token,
            "obtained_at": obtained_at,
            "expires_in": expires_in,
            "expires_at": obtained_at + expires_in
        }

    def get_config(self):
        yaml_data = get_yaml_data(self.CONFIG_FILE)
        self.base_url = yaml_data.get("base_url")
        self.corpid = yaml_data.get("corpid").get("hogwarts")
        self.corpsecret = yaml_data.get("corp_secret").get(self.CORPSECRET)
```

**缓存文件结构**（`token_cache.yaml`）：
```yaml
corpid_corpsecret_key:
  expires_at: 1789057854.0597079
  expires_in: 7200
  obtained_at: 1789050654.0597079
  token: 4APkdftnYvupILvFp3A8W...
```

**为什么用文件缓存而不是内存缓存？**
- 多进程场景下内存不共享
- 文件缓存更可靠，跨进程可用

**为什么提前 600 秒刷新？**
- 防止边界情况：刚好在过期瞬间发起请求被拒绝
- 网络延迟可能导致请求到达时 token 已过期

### 6.3 Department — 接口 CRUD 封装

**文件**：`frame/apis/departments.py`

```python
from jsonpath import jsonpath
from interface_auto.frame.apis.wework import Wework

class Department(Wework):
    CORPSECRET = "contacts"  # 通讯录管理应用密钥

    def create(self, data):
        create_url = f"{self.base_url}/cgi-bin/department/create?access_token={self.token}"
        req = {"method": "POST", "url": create_url, "json": data}
        return self.send_api(req)

    def update(self, data):
        update_url = f"{self.base_url}/cgi-bin/department/update?access_token={self.token}"
        req = {"method": "POST", "url": update_url, "json": data}
        return self.send_api(req)

    def delete(self, depart_id):
        delete_url = f"{self.base_url}/cgi-bin/department/delete?access_token={self.token}"
        req = {"method": "GET", "url": delete_url, "params": {"id": depart_id}}
        return self.send_api(req)

    def list(self):
        list_url = f"{self.base_url}/cgi-bin/department/simplelist?access_token={self.token}"
        req = {"method": "GET", "url": list_url}
        return self.send_api(req)

    def clear(self):
        '''清理所有部门（跳过 id=1 的根部门）'''
        r = self.list()
        id_list = jsonpath(r.json(), "$..id")  # 递归查找所有 id
        for i in id_list:
            if i != 1:
                self.delete(i)
```

**为什么 Department 继承 Wework？**
- 复用 token 获取能力，避免重复代码
- 自动拥有 `self.token`、`self.base_url` 等属性

### 6.4 测试用例 — 两种写法

**文件**：`tests/test_departments.py`

#### 写法一：业务流程测试

```python
import allure
import pytest
from jsonpath import jsonpath

from interface_auto.frame.apis.departments import Department
from interface_auto.frame.utils.file_util import get_yaml_data, get_path
from interface_auto.frame.utils.util import Utils

@allure.feature("部门管理")
class TestDepartments:

    def setup_class(self):
        self.department = Department()
        self.depart_id = 210
        self.create_data = {
            "name": "广州研发中心",
            "name_en": "RDGZ",
            "parentid": 1,
            "order": 1,
            "id": self.depart_id
        }
        self.update_name = "广州研发中心-update"
        self.update_data = {
            "id": self.depart_id,
            "name": self.update_name
        }
        self.department.clear()  # 清理数据，保证测试环境干净

    @allure.story("部门管理业务场景")
    @allure.title("部门增删改查场景测试")
    def test_department_flow(self):
        # 1. 创建部门
        with allure.step("创建部门"):
            r = self.department.create(self.create_data)
            assert r.status_code == 200
            assert r.json().get("errcode") == 0

        # 2. 查询创建成功
        with allure.step("查询创建成功"):
            r = self.department.list()
            depart_ids = jsonpath(r.json(), "$..id")
            assert self.depart_id in depart_ids

        # 3. 更新部门 + 数据库断言
        with allure.step("更新部门信息"):
            r = self.department.update(self.update_data)
            assert r.status_code == 200
            assert r.json().get("errcode") == 0
            # 数据库验证
            database_info = {
                "host": "mysql.hogwarts.ceshiren.com",
                "port": 3306,
                "database": "hogwarts_stu",
                "user": "stu",
                "password": "hogwarts_stu",
                "charset": "utf8"
            }
            datas = Utils.query_db(f"select name from departments where id=210", database_info)
            assert datas[0].get("name") == self.update_name

        # 4. 删除部门
        with allure.step("删除部门"):
            r = self.department.delete(self.depart_id)
            assert r.status_code == 200
            assert r.json().get("errcode") == 0

        # 5. 查询删除成功
        with allure.step("查询删除成功"):
            r = self.department.list()
            depart_ids = jsonpath(r.json(), "$..id")
            assert self.depart_id not in depart_ids
```

### 6.6 数据库断言

**文件**：`frame/utils/util.py`

```python
import pymysql
from pymysql.cursors import DictCursor

class Utils:
    @classmethod
    def query_db(cls, sql, database_info: dict):
        conn = pymysql.connect(**database_info, cursorclass=DictCursor)
        try:
            with conn.cursor() as cursor:
                cursor.execute(sql)
                datas = cursor.fetchall()
            logger.info(f"查询到的数据为: {datas}")
            return datas
        finally:
            conn.close()
```

**为什么需要数据库断言？**
- 接口返回 errcode=0 不代表数据真正写入数据库
- 数据库是最终数据源，DB 验证是最可靠的断言方式

### 6.8 路径工具

**文件**：`frame/utils/file_util.py`

```python
from pathlib import Path
import yaml

def get_path(path_name):
    '''获取项目内子目录路径'''
    src = Path(__file__).resolve().parent.parent  # 项目根目录
    dir_path = src / path_name
    dir_path.mkdir(exist_ok=True)
    return dir_path

def get_yaml_data(yaml_path):
    with open(yaml_path, encoding="utf-8") as f:
        return yaml.safe_load(f)

def write_yaml_data(yaml_path, datas):
    with open(yaml_path, "w", encoding="utf-8") as f:
        yaml.dump(datas, f)
```

## 九、AI 辅助接口自动化（MCP + OpenAPI）

### 9.1 核心概念

**MCP（Model Context Protocol）**：AI 模型与外部工具交互的标准协议，让 AI 可以直接调用接口、读取数据、执行操作。

**OpenAPI**：接口描述的行业标准，描述接口的路径、参数、请求/响应格式。

**awslabs.openapi-mcp-server**：将 OpenAPI 描述文件自动转换为 MCP 工具，一条命令启动，无需编写代码。

### 9.2 企业微信通讯录 API OpenAPI 最小接口集

| 接口 | 说明 |
|------|------|
| GET /gettoken | 获取 access_token |
| GET /user/get | 读取成员 |
| POST /user/create | 创建成员 |
| POST /user/update | 更新成员 |
| GET /user/delete | 删除成员 |

**鉴权方式**：access_token 以 query 参数传递。

### 9.3 AI 辅助的价值

从"写代码" → "描述需求"：
- 自动生成接口用例
- 自动调试接口
- 自动生成断言
- 自动执行测试

## 十一、面试高频题

1. **分层架构各层职责？为什么这样分层？**
   - 职责分离、可维护、可复用。utils 提供通用能力，base 统一 HTTP 封装，apis 按业务封装，tests 只关心断言。

2. **Token 缓存策略？为什么提前 600 秒刷新？**
   - 文件缓存避免重复请求，提前刷新防止边界情况（网络延迟导致刚好过期）。

3. **jsonpath 的 `$..id` 是什么意思？**
   - 递归查找所有 id 字段，不管嵌套多深。

4. **为什么需要数据库断言？**
   - 接口返回 errcode=0 不代表数据真正写入数据库，DB 是最可靠的断言方式。

5. **数据驱动测试怎么实现？**
   - `@pytest.mark.parametrize` + YAML 数据文件，每组数据一条用例。

6. **AI 辅助接口自动化（MCP + OpenAPI）是什么？**
   - MCP 是 AI 与外部工具交互的协议，OpenAPI 是接口描述标准，两者结合让 AI 自动调用接口、生成用例。
