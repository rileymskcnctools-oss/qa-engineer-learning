# Ch05 - 变量与布尔类型

## 1. 知识点理解

> 一句话解释：变量是给数据贴的标签，布尔类型是 Python 用来判断"对/错"的开关——测试断言全靠它。

| 维度          | 说明                                                                                |
| ----------- | --------------------------------------------------------------------------------- |
| **一句话解释**   | 变量 = 数据的名字；布尔 = 真（True）或假（False）                                                  |
| **为什么需要**   | 没有变量 = 每次用数据都得重写一遍；没有布尔 = 没法写"如果登录成功就...否则就..."                                   |
| **在测试中的作用** | 变量存测试数据（URL、用户名、期望值）；布尔是 `assert` 断言的底层——`assert 2+2 == 4` 本质是判断一个布尔表达式是不是 `True` |

## 2. Python 语法

### 2.1 变量定义

#### 语法格式

```python
变量名 = 值
# Python 是动态类型：不需要声明类型，变量类型跟着值走
# 赋值即定义，不存在"先声明后赋值"
```

#### 示例代码

```python
# 定义变量
name = "霍格沃兹"       # str
age = 18                # int
score = 98.5            # float
is_pass = True          # bool

# 动态类型：同一变量可以换成不同类型
name = "霍格沃兹"
name = 123              # 现在 name 是 int 了
print(type(name))       # <class 'int'>
```

#### 代码解释

| 行               | 作用                              |
| --------------- | ------------------------------- |
| `name = "霍格沃兹"` | ① 创建字符串 `"霍格沃兹"` ② 让 `name` 指向它 |
| `name = 123`    | `name` 不再指向字符串，改为指向整数 123       |
| `type(name)`    | 查看变量当前指向什么类型                    |

### 2.3 变量地址 — id()

#### 语法格式

```python
id(变量)    # 返回变量在内存中的地址（一串数字）
```

#### 示例代码

```python
# 同一个值的两个变量，可能指向同一地址
name = "霍格沃兹"
school = "霍格沃兹"

print(id(name))         # 例如：2048490646256
print(id(school))       # 同一地址（Python 对小字符串做了缓存）
print(id(name) == id(school))  # True → 它们是同一个对象

# 测试中的实用场景：确认两个变量是否指向同一个对象
a = [1, 2, 3]
b = a                   # b 指向 a 的同一个列表
print(id(a) == id(b))   # True → 改 b 也会影响 a
```

#### 代码解释

| 行                        | 作用                       |
| ------------------------ | ------------------------ |
| `id(name)`               | 获取 `name` 变量指向的对象在内存中的位置 |
| `id(name) == id(school)` | 判断两个变量是否指向同一个对象          |

### 2.4 布尔类型

#### 语法格式

```python
True    # 真
False   # 假
# bool 是 int 的子类：True == 1, False == 0
```

#### 示例代码

```python
# 1. 条件判断产生布尔值
x = 5
y = 10
print(x < y)    # True
print(x > y)    # False
print(x == 5)   # True

# 2. 状态标记
is_logged_in = False       # 初始未登录
# ... 执行登录 ...
is_logged_in = True        # 登录成功，更新状态

# 3. 测试断言 = 就是在判断布尔值
actual = 200
expected = 200
print(actual == expected)  # True → 测试通过
```

#### 代码解释

| 行 | 作用 |
|----|------|
| `x < y` | 比较运算 → 结果是 `True` |
| `is_logged_in = False` | 用布尔变量记录状态，比 `0`/`1` 可读性强 |
| `actual == expected` | 这就是断言的本质——比较结果是否 `True` |

### 2.5 假值：哪些情况算 False

#### 语法格式

```python
# 以下在 if 判断中等价于 False：
False       # 布尔假
None        # 空值
0, 0.0      # 数字零
""          # 空字符串
[]          # 空列表
{}          # 空字典
()          # 空元组
```

#### 示例代码

```python
# 测试中常见：检查接口返回数据是否为空

response_data = []          # 接口返回了空列表

if response_data:
    print("有数据，开始验证")
else:
    print("无数据，跳过验证")   # ← 会走这里

# 等同于：
if len(response_data) > 0:  # 冗长
    ...
if response_data:           # 简洁（Python 风格）
    ...
```

#### 代码解释

| 写法 | 等价于 | 推荐 |
|------|--------|------|
| `if data:` | `if bool(data) == True:` | ✅ 简洁 |
| `if len(data) > 0:` | 一样的效果 | 啰嗦 |
| `if data is not None and len(data) > 0:` | 过于防御 | 过度 |

## 4. 易错点

| 常见错误 | 错误原因 | 解决方法 |
|---------|---------|---------|
| 变量未定义就使用 | `print(xxx)` 但前面没有 `xxx = ...` | `NameError: name 'xxx' is not defined` → 先赋值 |
| 把 `=` 和 `==` 搞混 | `if x = 5:` 是赋值不是比较 | 比较用 `==`，赋值用 `=` |
| 动态类型反直觉 | `name = "123"` 再 `name = 123`，类型变了可能引发后续 Bug | 同一变量尽量不改类型 |
| `True` / `False` 大小写 | 写 `true` 或 `TRUE` | Python 是 `True`（首字母大写） |
| 空值判断用 `== None` 还是 `is None` | `==` 可以被重载，`is` 比较身份更安全 | 判断 None 用 `is None` |

## 7. 面试输出

> 30 秒能说完的回答。

**问题：Python 中哪些值会被判定为 False？代码里怎么用这个特性？**

**回答：** `False`、`None`、`0`、空字符串、空列表/字典/元组都会被判定为假。测试里最常用的场景是检查接口返回——写 `if response_data:` 代替 `if len(response_data) > 0:`，更 Pythonic。但要注意 `" "`（空格字符串）是真值，`0` 是假值——别把"没有数据"和"数据为 0"搞混。
