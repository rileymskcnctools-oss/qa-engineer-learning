# Ch03 - 输入和输出

## 1. 知识点理解

> 一句话解释：`input()` 让程序从键盘接收数据，`print()` 让程序把结果显示到屏幕——这是程序和人的对话通道。

| 维度 | 说明 |
|------|------|
| **一句话解释** | `input()` = 程序听你说，`print()` = 程序告诉你 |
| **为什么需要** | 没有输入=程序只能处理写死的数据；没有输出=程序运行了也不知道结果对不对 |
| **在测试中的作用** | 写测试脚本时很少用 `input()`（测试要自动化，不能等人工输入），但 `print()` 是调试神器——中断点之间打 `print()` 看变量值，比调试器还快。后续学到 Pytest，会用 `assert` 替代 `print` 做验证 |

## 2. Python 语法

### 2.1 input() — 输入函数

#### 语法格式

```python
变量 = input("提示信息")     # 提示信息可选
# input() 返回的一定是字符串（str），不是数字
```

#### 示例代码

```python
# 基本用法：无提示
name = input()
print("您好，" + name + "！")

# 友好用法：带提示
name = input("请输入您的姓名：")
print("您好，" + name + "！")

# 测试中可能会用到的场景：读取测试数据
test_data = input("请输入测试用户名：")   # 输入 admin
print("将使用用户", test_data, "进行测试")
print("数据类型：", type(test_data))      # <class 'str'>
```

#### 代码解释

| 行 | 作用 |
|----|------|
| `name = input()` | 程序暂停，等键盘输入。输入的内容赋给 `name` |
| `input("请输入...")` | 括号里写提示文字，用户体验更好 |
| `type(test_data)` | 验证 input 返回的是字符串——输入 `123` 不是数字，是字符串 `"123"` |

---

### 2.2 print() — 输出函数

#### 语法格式

```python
print(values, sep=" ", end="\n")
# values : 要输出的内容（可以有多个，逗号分隔）
# sep    : 多个内容之间的分隔符，默认空格
# end    : 输出结尾加什么，默认换行符 \n
```

#### 示例代码

```python
# 1. 基本输出
print("Hello World")                      # → Hello World

# 2. 输出多个数据（默认空格分隔）
print("Hello", "Python", 20, True)        # → Hello Python 20 True

# 3. 指定分隔符 sep
print("Hello", "Python", 20, True, sep='---')
# → Hello---Python---20---True

# 4. 指定结束符 end（不换行）
print("Hello", end="")
print("World")
# → HelloWorld（两行打印连在一起）

print("Python", end="---")
print("Java")
# → Python---Java
```

#### 代码解释

| 行 | 作用 |
|----|------|
| `print("Hello World")` | 输出一个字符串，末尾自动换行 |
| `print("Hello", "Python", 20, True)` | 4 个数据用空格连接输出 |
| `sep='---'` | 不用默认空格，改用 `---` 分隔 |
| `end=""` | 打印完不加换行 → 下一个 `print` 接在这行后面 |
| `end="---"` | 打印完加 `---` 而不是换行 |

## 3. 测试应用场景

| 场景 | 怎么用 | 对应阶段 |
|------|--------|---------|
| 测试用例 | `print()` 调试：在断言前后打印关键变量值，确认数据流向 | 目前 |
| 自动化脚本 | 脚本跑完后 `print("测试完成，共执行 X 条用例")` 输出摘要 | 后续 |
| Pytest 集成 | Pytest 中一般不用 `print()`，用 `assert` 断言 + `-s` 参数才能看到 print 输出 | 后续 |

> 说明：目前只需要关注「测试用例」列。测试脚本里 `print()` 主要用来调试，正式验证靠后面的 `assert`。

## 4. 易错点

| 常见错误 | 错误原因 | 解决方法 |
|---------|---------|---------|
| `input()` 拿到的是字符串 | `age = input()` 输入 18，`age` 是 `"18"` 不是数字 18 | 需要数字时加 `int(input())` |
| `print("a"+"b")` vs `print("a","b")` | `+` 是拼接（无空格），`,` 是多个参数（默认空格分隔） | `+` → `ab`，`,` → `a b` |
| `print("Hello" end="")` 忘了逗号 | `end` 是参数，前面需要逗号 | 正确：`print("Hello", end="")` |
| `sep` 和 `end` 混用 | `sep` 管"数据之间的分隔"，`end` 管"整句末尾加什么" | 记忆：s=separator 分隔，e=end 结尾 |

## 6. 自动化关联

| 关联框架 | 关系说明 | 学到时会怎么用 |
|---------|---------|--------------|
| **Pytest** | Pytest 默认不显示 `print()`，加 `-s` 参数才显示 | `pytest -s test_login.py` 看调试输出 |
| **Selenium** | 浏览器操作步骤用 `print()` 输出日志，方便定位卡在哪一步 | `print("正在点击登录按钮...")` |
| **Playwright** | Playwright 自带 trace，但 `print()` 仍是最快的临时调试手段 | 出问题时 `print(page.title())` 确认当前页面 |

## 7. 面试输出

> 30 秒能说完的回答。

**问题：`input()` 和 `print()` 在测试脚本中怎么用？**

**回答：** 测试脚本里基本不用 `input()`，因为测试要自动化执行，不能停下来等人输入。`print()` 是调试利器——在断言前后打印关键变量，快速定位数据在哪一步出错。注意 `print()` 默认换行，多个 `print()` 想输出在同一行用 `end=""`。学到 Pytest 后，正式验证用 `assert` 替代 `print`。
