## 一、什么是循环

### 知识点 1：为什么需要循环

【课程原话/定义】
反复做同一件事的情况，称为循环。循环主要有两种：计次循环（for-in）和条件循环（while）。Python 中没有 do…while 循环。

【为什么？】
没有循环，你要对 100 个测试数据做同一个断言，就得把断言代码复制 100 遍——这还叫编程？循环让你把"重复做的事情"只写一次。测试中最典型的场景：遍历用例列表逐个执行、等待某个条件满足后继续（轮询接口状态直到返回成功）。

【必须掌握】
- 循环两大类型：计次循环（知道次数）→ for-in；条件循环（知道结束条件）→ while
- Python 的 for-in 不是 C 语言的传统 for 循环，是增强型（遍历可迭代对象）

【企业场景】
> 接口自动化中，你提交了一个异步任务，需要轮询等待结果：`while task_status != "completed": time.sleep(2); task_status = check_status(task_id)`。这就是条件循环的经典用法——你不知道要等多久，只知道"直到状态变成 completed"。

### 知识点 2：循环的四个构成要素

【课程原话/定义】
- **初始化语句**：循环开始前执行，初始化变量
- **循环条件**：布尔表达式，决定是否继续循环
- **循环体**：被重复执行的代码块
- **迭代语句**：每次循环体执行后，向结束条件趋近

【为什么？】
这四个要素缺一不可。少初始化→变量未定义；少条件→不知道何时停；少循环体→循环没意义；少迭代→死循环。理解这四个要素，你就能分析任何一段循环代码——不管多复杂，拆成这四部分就清晰了。

【必须掌握】
能用这四个要素分析一段 while 循环代码，标注每部分对应哪行。

【企业场景】
> 分析一段测试轮询代码的四要素：
> ```python
> retry = 0                        # ①初始化
> while retry < 3:                 # ②条件
>     response = requests.get(url) # ③循环体
>     if response.ok: break
>     retry += 1                   # ④迭代
> ```

【面试考察】
> 面试官："用四要素分析一段你写的循环代码。"
> 参考回答：先标注初始化、条件、体、迭代各对应哪行，然后说明每部分的作用。面试官想看的是你是否有结构化的代码分析能力，而不是"会写循环就行"。

【我的理解】

## 二、while 循环

### 知识点 3：while 循环语法与执行流程

【课程原话/定义】

```python
while 条件表达式:
    循环体
```

当条件表达式为真时，执行循环体；执行完毕后重新判断条件，直到条件为假时退出。

【为什么？】
while 的核心是"只要……就一直……"。和 if 的区别：if 只判断一次，while 反复判断直到条件不成立。while 在测试中最适合那些"不知道要等多久但知道等待结束条件"的场景——比如轮询、重试、等待元素出现。

【必须掌握】
- 条件表达式后面有冒号
- 循环体必须缩进
- 循环体内部必须有改变条件的语句，否则死循环
- `while True:` + `break` 是合法且常见的模式（有意死循环 + 内部跳出）

【企业场景】
> ① 接口重试：`while retry_count < max_retries: ... retry_count += 1`
> ② 等待页面元素出现：`while not driver.find_element(...): time.sleep(1)`（Selenium 实际用 WebDriverWait 封装了）
> ③ 密码输入重试：`while input_pwd != correct_pwd: input_pwd = input("请重新输入: ")`

【面试考察】
> 面试官："`while True:` 是死循环吗？什么时候会用它？"
> 参考回答：是死循环，但内部配合 `break` 可以跳出。用于"不知道循环次数，由内部逻辑决定何时退出"的场景——比如服务监听请求：`while True: handle(client.accept())`，或者测试中轮询任务状态直到成功。这是公认的 Python 惯用写法，比设一个巨大的上限数字更清晰。

【易错点】

| 错误 | 后果 | 正确做法 |
|------|------|---------|
| 忘记更新循环变量 | 死循环 | 检查循环体内有无 `n += 1` 之类的语句 |
| 条件永远为 True 且无 break | 死循环 | `while True` 必须有 `break` |
| 条件写反（`while n > 10` 但 n 初始为 1） | 循环一次都不执行 | 检查初始值和条件的逻辑方向 |
| 循环变量更新位置错误 | 少乘一次/多乘一次 | 把更新放在循环体末尾 |

## 三、while 循环实战

### 知识点 4：实战案例

【课程原话/定义】
三个实战：①求 1~10 乘积；②密码验证；③数 7 游戏。

【必须掌握】
能独立写出这三个案例，并标注四要素。

【实战 1：求 1~10 乘积】

```python
result = 1      # ①初始化
n = 2           # ①初始化（从2开始，乘1没意义）
while n <= 10:  # ②条件
    result *= n # ③循环体
    n += 1      # ④迭代
print(result)   # 3628800
```

【实战 2：密码验证】

```python
password = "password"
input_password = ""
while input_password != password:       # ②条件（同时也是③循环体的一部分）
    input_password = input("请输入: ")   # ③循环体 + ④迭代（用户输入推进条件）
print("登录成功！")
```

【实战 3：数 7 游戏（找出 1~100 中含 7 或 7 的倍数的数）】

```python
n = 1
while n <= 100:
    if n % 7 == 0 or "7" in str(n):   # 7的倍数 或 包含数字7
        print(n)
    n += 1
```

【企业场景】
> 实战 2 直接对应登录测试中的重试逻辑。实战 3 体现了"条件筛选 + 循环"的组合——这本质上就是测试中"遍历结果集 + 过滤异常数据"的模式：`while 还有数据: if 数据异常: 记录下来; 继续下一条`。
